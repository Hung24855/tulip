# 🌷 Bó Hoa Tulip - Ngày Phụ Nữ Việt Nam 20/10

Website nghệ thuật tặng hoa Tulip và gửi gắm bức thiệp tình yêu nhân ngày Phụ nữ Việt Nam 20/10.

## ✨ Điểm nổi bật
- 🌷 **11 đóa hoa Tulip nở rộ**: Hiệu ứng nở từng cánh hoa mượt mà, rực rỡ dưới bầu trời đêm ngập tràn ánh sao và sao băng lướt qua.
- 💌 **Bức thiệp tình yêu nghệ thuật**: 
  - Phong bì sáp trái tim nổi 3D (`❤️`) gắn trên nơ satin hồng.
  - Hiệu ứng bung mở kịch tính: nắp phong bì mở 3D, con dấu trái tim bay vút lên giữa màn hình và bung nở nhẹ nhàng.
  - Thiệp thư viền lượn sóng (SVG deckle edge) màu hồng phấn, phông chữ viết tay lãng mạn `Dancing Script`.
  - Hiệu ứng hiện dần từng dòng chữ đầy cảm xúc, hỗ trợ chạm để đọc ngay hoặc phím `Esc` để đóng.
- 🎶 **Giai điệu lãng mạn nhẹ nhàng**: Tích hợp bộ tổng hợp âm thanh Web Audio Synthesizer du dương, không phụ thuộc file âm thanh ngoài.
- 📱 **Tương thích hoàn hảo mọi thiết bị**: Tự động co giãn mượt mà trên Mobile, Tablet và Desktop.
